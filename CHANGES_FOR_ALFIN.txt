Alfin 你好，最近在 issue-hook 和 forge 这边做了一轮改动，跟你同步一下：

1）抓 issue 时会顺带把每个 PR 的 base_sha、head_sha 和完整 patch 写进最终 JSON 里了，后面跑测试不用再单独拉。patch 拉不到就跳过，不报错。

2）forge 那边修了 .env 的读取：现在会从项目根目录读 .env，并且用 override 让 .env 里的 MODEL、FORGE_BASE_URL 真正生效，不会再出现你配了 tensorblock/gpt-4.1-mini 还走 OpenAI/gpt-4o 的情况。

3）issue 爬虫加了 patch 的过滤。一是「必踢」：只改文档（docs、md、rst）、只改锁文件/配置（package-lock、Cargo.lock、dist、build 等）、只改 vendor/third_party/node_modules、纯二进制（图片 zip pdf 等）、以及纯格式化（比如 run formatter）的 PR 会直接排除。二是可选的行数范围：可以设增加行数、删除行数的最大最小，还加了一个「总行数」（增加+删除）的最大最小，不配就相当于不限制。

4）Excel 里那 11 个问题的「Can be fixed?」那一列我按之前的修复思路填了简短说明，方便你对一下。
